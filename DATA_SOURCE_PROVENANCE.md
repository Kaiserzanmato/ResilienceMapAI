# Current Event Provenance

Every `GET /api/events` record has a canonical `event_id` (`provider:provider_event_id`), provider name, source tier, authority classification, source URL, source update/event time where supplied, and retrieval time. The API returns raw metadata only from bounded allowlisted provider fields.

USGS event IDs and source URLs are retained and records are `official=true`, Tier 5. GDACS records are Tier 4 and `official=false`; their alert status is not a national-agency instruction. EONET and ReliefWeb are supplemental Tier 4 records. ReliefWeb text remains untrusted external data and is not passed to AI by this implementation.

Duplicate records from the same provider collapse by canonical event ID. Potentially related cross-provider records remain independent records and receive conservative `related_event_ids` only when hazard taxonomy, event time (within 24 hours), and point proximity (within 100 km) agree.

## Philippine volcanoes (Volcanic Activity score and wildfire's volcano-heat filter)

Source: **DOST-PHIVOLCS, List of Philippine Volcanoes**
(https://www.phivolcs.dost.gov.ph/volcanoes-of-the-philippines/), used with PHIVOLCS's written permission in a letter dated
15 Oct 2026 (Director Teresito C. Bacolcol). Conditions: DocypherLabs use only, no redistribution; no changes to the
information; full acknowledgement of PHIVOLCS as the source with proper citation; send PHIVOLCS screenshots of where the
information is shown.

The list is generated by `backend/scripts/build_phivolcs_volcanoes.py` (names and coordinates verbatim) into a gitignored file
and supplied to the server via `VOLCANO_DATA_FILE`; it is never committed, and no API route, export or share link returns volcano
coordinates or the full list. It feeds the Volcanic Activity distance score and `wildfire_scoring.exclude_volcano_heat` (5 km).
The earlier Smithsonian GVP summit constant was removed. See [docs/WILDFIRE_VOLCANIC.md](docs/WILDFIRE_VOLCANIC.md) and
[issue #34](https://github.com/Kaiserzanmato/ResilienceMapAI/issues/34).
