# Argos Translate

Official project: https://github.com/argosopentech/argos-translate. Offline open-source machine translation with downloadable language models. Model licensing, language-pair quality, CPU/RAM, cold start, and emergency-term fidelity require an isolated benchmark before service adoption. Risks: unsafe medical/emergency mistranslation and operational model distribution. Recommendation: PROTOTYPE only; static UI must use dictionaries, retain original advisory text, cache by content/model/language, and require human validation for emergency terminology.
