# National and Local Sources

PAGASA, PHIVOLCS and NDRRMC are Tier 5 Philippine authorities. PAGASA publishes official tropical-cyclone bulletins, but this review found no stable, supported machine interface suitable for automatic production ingestion; the existing registry correctly keeps these manual-grounding-only. Facility data must be evaluated LGU-by-LGU with written license, update owner, coordinate quality, verification date and operational-status semantics. Recommendation: FUTURE; use approved uploads/imports only, with `OFFICIAL` only where source provenance proves it.
