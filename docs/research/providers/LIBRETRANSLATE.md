# LibreTranslate

Official docs: https://docs.libretranslate.com/ and https://docs.libretranslate.com/api/. REST API with detect/languages/translate endpoints, configurable rate and character limits, and Argos-backed translation. The project is AGPL-3.0; managed hosting is paid and self-hosting adds an operational service. Risks: copyleft review, model quality, resource use, translation of untrusted HTML, and provider failure. Recommendation: REJECT for this release; do not add a dependency or service.
